# Модули JARVIS

Документ описывает текущую архитектуру проекта JARVIS и назначение основных модулей системы.

---

# Core

Основное ядро ассистента.

Отвечает за формирование личности JARVIS и создание системного контекста перед обработкой каждого запроса.

Включает:

- Identity;
- Principles;
- Response Style;
- System Prompt.

Особенности реализации:

- ядро хранится в PostgreSQL (`jarvis_config`);
- автоматически загружается при каждом запросе;
- не зависит от используемого интерфейса (Telegram, Web и др.).

---

# Input Gateway

Единая точка входа для всех пользовательских запросов.

Назначение:

- приём сообщений из внешних интерфейсов;
- преобразование данных в единый внутренний формат;
- передача запроса в остальные модули системы.

Это позволяет добавлять новые интерфейсы без изменения внутренней логики JARVIS.

---

# Intent Router

Модуль маршрутизации запросов.

Определяет дальнейший сценарий обработки сообщения.

В зависимости от запроса может:

- обратиться к памяти;
- вызвать один или несколько инструментов;
- передать запрос напрямую языковой модели.

---

# Memory

Модуль долговременной памяти пользователя.

Функции:

- AI-классификация новых воспоминаний;
- сохранение фактов;
- обновление существующих записей;
- удаление воспоминаний;
- семантическая онтология памяти;
- разрешение синонимов через `resolve_ontology()`;
- гибридный поиск (Keyword + pgvector);
- Smart Recall Filter;
- формирование пользовательского контекста.

Используемые технологии:

- PostgreSQL 17;
- pgvector;
- OpenAI Embeddings.

---

# AI

Модуль взаимодействия с языковой моделью.

Отвечает за:

- обработку пользовательских запросов;
- использование личности JARVIS;
- использование долговременной памяти;
- работу с инструментами;
- генерацию ответов.

Используемая модель:

- OpenAI GPT-4.1 Mini.

---

# Tools

Модуль внешних инструментов.

Позволяет ассистенту выполнять действия вне языковой модели.

Реализовано:

- Internet Search (SearXNG);
- Docker Tool;
- SSH Tool.

Планируется:

- PostgreSQL Tool;
- File Tool;
- GitHub Tool;
- Health Tool;
- Calendar Tool.

---

# Automation

Модуль автоматизации.

Построен на платформе n8n.

Отвечает за:

- обработку входящих сообщений;
- маршрутизацию запросов;
- вызов инструментов;
- сохранение памяти;
- поиск воспоминаний;
- сборку контекста;
- взаимодействие с языковой моделью.

---

# Interfaces

Интерфейсы взаимодействия пользователя.

Реализовано:

- Telegram Bot.

Планируется:

- Web Interface;
- Voice Interface;
- REST API;
- мобильное приложение.

---

# Storage

Модуль хранения данных.

Используется:

- PostgreSQL 17;
- pgvector.

Хранит:

- ядро JARVIS;
- долговременную память;
- онтологию памяти;
- embeddings;
- служебную конфигурацию проекта.

---

# Context Pipeline

Текущий процесс обработки пользовательского запроса:

```text
Telegram
      │
      ▼
Input Gateway
      │
      ▼
Intent Router
      │
      ▼
Recall Memory
 ├── Keyword Search
 └── Vector Search
      │
      ▼
Merge Recall
      │
      ▼
Smart Recall Filter
      │
      ├────────────► Load JARVIS Core
      │
      ▼
Build Context
      │
      ▼
AI Agent
 ├── Memory Tool
 ├── SearXNG Tool
 ├── Docker Tool
 └── SSH Tool
      │
      ▼
Telegram Reply
```
