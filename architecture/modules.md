# Модули JARVIS

Документ описывает текущую архитектуру проекта JARVIS и назначение каждого основного модуля.

---

# Core

Главное ядро ассистента.

Отвечает за формирование личности JARVIS и построение полного контекста перед каждым запросом.

Включает:

- Identity
- Principles
- Response Style
- System Prompt

Особенность текущей реализации:

Ядро хранится в PostgreSQL (`jarvis_config`) и автоматически загружается перед каждым запросом.

---

# Memory

Модуль долговременной памяти пользователя.

Функции:

- сохранение новой информации;
- AI-классификация памяти;
- удаление воспоминаний;
- семантический поиск;
- фильтрация релевантной памяти;
- формирование пользовательского контекста.

Используемые технологии:

- PostgreSQL
- pgvector
- OpenAI Embeddings

---

# AI

Модуль взаимодействия с языковой моделью.

Отвечает за:

- обработку запросов;
- использование личности JARVIS;
- использование долговременной памяти;
- генерацию ответов.

Используемая модель:

- OpenAI GPT-4.1 Mini

---

# Automation

Модуль автоматизации.

Текущая реализация построена на n8n.

Отвечает за:

- Telegram Workflow;
- обработку сообщений;
- сохранение памяти;
- Recall;
- загрузку ядра;
- сборку контекста.

---

# Interfaces

Интерфейсы взаимодействия пользователя.

Реализовано:

- Telegram Bot

Планируется:

- Web Interface
- Voice Interface
- REST API

---

# Storage

Модуль хранения данных.

Используется:

- PostgreSQL 17
- pgvector

Хранит:

- долговременную память;
- embeddings;
- конфигурацию ядра JARVIS.

---

# Context Pipeline

Текущий процесс формирования контекста:

```text
Telegram
      │
      ▼
Generate Embedding
      │
      ▼
Recall Memory
      │
      ▼
Smart Recall Filter
      ├────────────► Load JARVIS Core
      │
      ▼
     Merge
      │
      ▼
 Build Context
      │
      ▼
 OpenAI Agent
      │
      ▼
Telegram Reply
```
