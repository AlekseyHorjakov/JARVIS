# Research Skill

## Назначение

Research Skill отвечает за поиск, анализ, сравнение и структурирование информации.

Навык используется только тогда, когда запрос пользователя требует получения или анализа информации из внешних источников.

---

## Основные задачи

- Поиск информации.
- Анализ найденных данных.
- Сравнение нескольких источников.
- Подготовка кратких и подробных обзоров.
- Поиск документации.
- Поиск технических решений.
- Анализ технологий.
- Исследование рынка.
- Сбор фактов.

---

## Когда использовать

Использовать навык, если пользователь просит:

- найти информацию;
- провести исследование;
- сравнить технологии;
- изучить документацию;
- собрать сведения;
- проанализировать данные;
- подготовить обзор;
- проверить факты.

---

## Когда НЕ использовать

Навык не используется, если запрос относится к:

- личной памяти пользователя;
- выполнению команд на сервере;
- работе с PostgreSQL;
- работе с Docker;
- управлению GitHub;
- другим специализированным Skills.

---

## Используемые инструменты

- Web Search

---

## Результат работы

Навык должен предоставить:

- достоверную информацию;
- краткое объяснение;
- структурированный вывод;
- ссылки на использованные источники (если применимо).
