# Спецификация системы Skills (v1)

## Назначение

Skills — это подключаемые функциональные модули JARVIS, расширяющие возможности ассистента без изменения его ядра.

Каждый Skill представляет собой самостоятельный компонент, выполняющий одну конкретную задачу.

---

# Основные принципы

- один Skill — одна ответственность;
- независимость от других Skills;
- возможность подключения и отключения без изменения JARVIS Core;
- единый формат взаимодействия;
- возможность повторного использования в разных workflow.

---

# Структура Skill

Каждый Skill должен содержать:

- описание назначения;
- входные параметры;
- выходные данные;
- используемые инструменты;
- обработку ошибок;
- документацию.

В следующих версиях Skills будут обладать единым интерфейсом подключения, собственными настройками и возможностью независимого развития без изменения архитектуры JARVIS Core.
