# JARVIS Core v1.1 — Архитектура

## Принцип

Core развивается инфраструктурно.

Новая функциональность реализуется только через Skills.

---

# Слои

```
Input Gateway
      │
Intent Router
      │
Skill Dispatcher
      │
Context Builder
      │
Agent
```

---

# Core отвечает только за

- приём сообщений;
- маршрутизацию;
- сбор контекста;
- вызов навыков;
- возврат ответа.

---

# Core НЕ отвечает за

- анализ документов;
- анализ переписок;
- медицину;
- финансы;
- планирование;
- обработку изображений.

---

# Skill Dispatcher

Назначение:

- определить подходящий Skill;
- передать входные данные;
- получить результат;
- вернуть управление Core.

---

# Skill Contract

Каждый Skill обязан иметь:

- manifest;
- описание;
- входной контракт;
- выходной контракт;
- версию.

---

# Context Providers

Каждый источник контекста независим:

- Memory
- Projects
- Conversation
- Health
- Calendar

Context Builder объединяет только необходимые части.

---

# Conversation Intelligence

Первый крупный Skill.

Возможности:

- анализ переписок;
- извлечение задач;
- списки покупок;
- ответственные;
- решения;
- даты;
- итоговое структурированное JSON.

---

# Правила развития

1. Core не содержит бизнес-логики.
2. Любая новая возможность = новый Skill.
3. Skills независимы друг от друга.
4. Core не знает внутреннюю реализацию Skills.
5. Все Skills работают через единый контракт.
