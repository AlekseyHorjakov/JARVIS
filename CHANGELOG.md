# Changelog

Все значимые изменения проекта JARVIS фиксируются в этом файле.

Формат основан на принципах **Keep a Changelog**.

# [1.1.0] - 2026-07-31

## Добавлено

### Архитектура

- реализован модуль **Input Gateway**;
- добавлен **Intent Router** для маршрутизации пользовательских запросов;
- переработан процесс сборки контекста;
- обновлена архитектура обработки сообщений.

### Long-Term Memory v2

- реализована семантическая онтология памяти;
- добавлены таблицы `memory_ontology` и `memory_ontology_aliases`;
- реализована PostgreSQL-функция `resolve_ontology()`;
- добавлено автоматическое разрешение синонимов и алиасов;
- внедрено атомарное хранение фактов;
- реализовано безопасное создание новых понятий через `ON CONFLICT`;
- улучшена устойчивость к конкурентным обращениям.

### Recall

- реализован гибридный поиск (Keyword + pgvector);
- добавлен Smart Recall Filter;
- улучшена релевантность извлекаемой памяти;
- оптимизировано формирование контекста для LLM.

### Tools

- интегрирован Internet Search (SearXNG);
- добавлен Docker Tool;
- добавлен SSH Tool;
- реализована поддержка Tool Calling.

### Infrastructure

- обновлена структура проекта;
- подготовлена архитектура для дальнейшего расширения новыми инструментами;
- улучшена документация проекта.

# [1.0.0] - 2026-07-27

## Добавлено

### JARVIS Core

- реализовано ядро личности JARVIS;
- добавлены Identity, Principles, Response Style и System Prompt;
- ядро вынесено в PostgreSQL (`jarvis_config`);
- создан скрипт автоматического развертывания `deploy_core.py`.

### Long-Term Memory

- реализована долговременная память пользователя;
- добавлена AI-классификация памяти;
- реализован семантический поиск (pgvector);
- добавлено сохранение новых воспоминаний;
- реализено удаление воспоминаний;
- реализованы контекстные ответы на основе памяти.

### Workflow

- реализован полный pipeline обработки сообщений;
- добавлена загрузка JARVIS Core перед каждым запросом;
- реализована сборка общего контекста (`Build Context`);
- реализован Recall памяти;
- добавлена фильтрация релевантной памяти.

### Infrastructure

- PostgreSQL 17;
- pgvector;
- Docker;
- n8n;
- Telegram Bot;
- OpenAI GPT-4.1 Mini.
