# Contributing

На текущем этапе проект разрабатывается одним автором.

Внешние pull request'ы, issue и предложения по изменению архитектуры пока не принимаются.

Если в будущем проект станет открытым для совместной разработки, данный документ будет расширен и будет содержать:

- правила оформления изменений;
- требования к стилю кода;
- процесс code review;
- требования к документации;
- правила оформления commit message;
- порядок работы с ветками Git.

До этого момента вся архитектура и документация изменяются только владельцем проекта.
